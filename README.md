## Overview

This repository contains JavaScript exercises focused on object-oriented programming, class syntax, private fields, and methods that manage internal state.

## Tech Stack

- JavaScript
- HTML
- Object-Oriented Programming
- Git & GitHub

## Tasks

### Customer Object
Implements methods for retrieving and updating customer data, applying discounts, and processing orders using `this`.

### Storage Class
Implements a class with a private `#items` field and methods to add, remove, and retrieve stored items.

### StringBuilder Class
Implements a class with a private string value and methods for adding content to the beginning, end, or both sides.

## Learning Outcomes

- `this` context;
- JavaScript classes;
- constructors and instance methods;
- private class fields;
- encapsulation and state management.
